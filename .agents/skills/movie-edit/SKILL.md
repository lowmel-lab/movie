# 動画編集

動画編集を頼まれたら、素材にアクセスできる場合はMP4を書き出して保存する。

1. 指定された動画、Driveリンク、添付、`input/` の順で素材を決める。Driveを使う場合は [Driveの転送と保存](references/drive.md) を読む。指定がなければ添付順またはファイル名の自然順を使う。素材にアクセスできなければ、その理由と必要な操作を伝える。
2. 案件ごとに `output/` の下に作業フォルダを作り、`words.json` と `plan.json` を保存する。修正時は同じ案件の素材と文字起こしを再利用し、新しい設計図と初稿は別名で保存する。`editing-rules.md` があれば依頼と両立する編集上の好みを適用する。
3. [テロップ・カット・音の設計](references/edit-plan.md) を読み、ローカルで文字起こしを行う。発話と必要な映像・音を確認して、語番号で編集を指定する。同じ案件の複数素材は本編と別アングル・差し込みを見極め、同じ内容を繰り返さない。参考動画やトランジションを指定されたら、色、文字、音の強さと切り替えを確認して反映する。
4. `scripts/edit_story.py` の `--check` で重複やカットをまたぐテロップを直してから書き出す。時刻付きの発話を確認できない場合は、視聴できる素材を使って映像と音声の調整で初稿を出し、字幕の有無を伝える。環境音や曲を残す場合は音の意図に合わせて調整する。
5. `ffprobe` で長さ・画角・映像と音声を確認し、代表箇所のテロップとカットを確認する。カットの多い動画では書き出し音声も文字起こしし、残すはずの文の欠落や繰り返しがないか聞き直す。
6. [Driveの手順](references/drive.md) で確認後のMP4を保存し、同じGoogleアカウントで読み返して保存先のリンクを返す。保存が中断された場合は元のMP4を再利用し、ローカルの初稿と具体的な失敗理由を伝える。

「今後も」など継続して適用する編集指示を受けた場合は、一般化できる内容を `editing-rules.md` に記録する。
