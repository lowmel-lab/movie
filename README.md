# movie

Codexでこのリポジトリを開き、動画を添付して「編集をお願い」と送ると、編集を開始します。動画をリポジトリ直下の `input/` に入れてから頼むこともできます。カット位置や画角などの希望があれば、依頼と一緒に伝えてください。

おまかせの初稿では、長い無音を詰め、音量を調整し、複数の動画を順番につないで `output/` にMP4を保存します。複数素材では先頭の動画に画面サイズを合わせ、比率が異なる素材には余白を入れます。`input/` に複数の素材を置く場合は `01-オープニング.mp4` のようにファイル名で順番を指定できます。

素材と書き出しはこの作業環境に保存され、Gitの管理対象外です。新しい環境で編集するときは、そこで編集する動画を添付するか `input/` に置いてください。

## コマンドで実行する場合

Python 3.10以降と、H.264・AACをエンコードできるFFmpeg（`ffmpeg` と `ffprobe`）が必要です。

```sh
python3 scripts/edit_preview.py --output output/初稿.mp4 -- input/01.mov input/02.mp4
```

曲や間を残したい場合は `--keep-pauses` を指定します。同名の出力がある場合は別の名前を指定してください。
